# このプロジェクトについて

**`Glob`,`Grep`のToolの実行を必要なくする** 

これによる、より快適な`Agentic Coding`の実現を目指す上で、

- `Agent Skill`による複数の各種CLIの利用ナレッジの提供
- `MCP`によるAIとの接続
- `SubAgent`によるメインコンテキストからの分離

どれもまだ非効率であると考えたため、
**各種ファイルの内容や位置に応じて、対象のファイルにタグをつける**
という方法で対応すれば、`Glob`,`Grep`いらずになるんではないか
という発想。

## タグのつけ方
　
### 位置

まず、位置の基準は以下

- プロジェクトルートから見て、どれくらいの階層があるか
- そのファイルを持つディレクトリ名はどういうものか

そのため、前提としてそのプロジェクト内のディレクトリ構成は
**コロケーション構成を取っている**ことが前提となる。

### 内容

- ファイル内に頻出する特定のワードの抽出
- 特定の役割を示すワードの有無

そのため、前提として、そのファイル内のプログラムが
**SOLID（単一責任）を遵守している**ことが前提となる
